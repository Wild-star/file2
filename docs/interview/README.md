## 内容结构

- **速成指南**：按"你的现有经验和这个岗位的接口在哪"组织，不是通用求职模板。
- **八股 74 问**：每问按"一句结论 → 一层原因 → 一个可验证的证据"三段式作答，难度标 ★/★★/★★★，文末附"必须脱口而出的 15 题"优先级表。
- **手撕两册**：算法题用 C++（华为机试支持），AI 手撕用 Python；两册都给出可运行代码的关键断言与验证方法（含与 `F.scaled_dot_product_attention`、`F.cross_entropy` 的对拍思路）。
- **速查卡**：面试前 10 分钟用，只保留骨架与关键词。
