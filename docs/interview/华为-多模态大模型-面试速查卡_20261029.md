**开场 30 秒自述**：我做过视觉+激光两种异构模态在统一 BEV 网格上的对齐融合，并负责过数据生产、指标归因、大规模训练稳定性、ONNX→ATC→MDC 端侧部署整条链路。多模态大模型我最有底气的是跨模态对齐、长序列建模、大规模训练调优和推理落地四块，VLM 的结构与 SFT/偏好对齐在系统补齐。

## A. 必须脱口而出的 15 问（只看关键词）

| 问 | 一句话答案 |
|---|---|
| ViT / token 数 | patch 切块 + 线性投影 + 位置编码；224/16→196、384×704/16→1056、4K/patch14→42,196 |
| 视觉 token 太多 | 池化/Perceiver-Q-Former/token merge/pixel shuffle/剪枝；**我的 BEV query 就是几何约束下的 token 重组** |
| CLIP | 双塔 + 对称 InfoNCE，batch 内 2(B−1) 个负样本；**大 batch 是命门** |
| LLaVA 为什么 MLP 够 | 冻结双塔下简单投影≈Q-Former；token 预算宽松选 MLP，紧就压 query |
| 对齐三层 | 表征对齐 / 粒度(region)对齐 / 行为对齐(SFT+偏好) |
| VLM 三件套 | 视觉塔 + 桥接层 + LLM；细节是占位 token 与冻结策略 |
| 训练三阶段 | 对齐只训 projector → SFT 解冻 LLM（只对 assistant 算 loss）→ 偏好对齐 |
| LoRA | ΔW=BA 低秩，只给 A/B 存梯度与优化器状态；rank 8~64、alpha≈2r；推理可合并零延迟 |
| 显存 | 参数 2P + 梯度 2P + 优化器 12P + 激活；ZeRO 1/2/3 + 检查点 + bf16 |
| 幻觉根因 | **语言先验压过视觉证据**：数据噪声/自回归偏好流畅/视觉 token 弱/缺拒答样本 |
| 评测 | MMBench(CircularEval) / MMMU(学科推理) / POPE(幻觉) / HallusionBench / RefCOCO(grounding) / VideoMME |
| POPE | random / popular / **adversarial**（只报随机负样本会虚高） |
| KV cache | 2·层数·kv头·dhead·seq·batch·字节；32层/32头/d128/2048 ≈ 1.07GB |
| Prefill vs Decode | 前者计算密集（大 GEMM），后者访存密集（读权重+KV） |
| 昇腾（送分） | CANN→ATC→AOE→AscendCL→`.om`；算子不支持要拆/等价改写、精度对齐、动态 shape 分档 |

## B. 手撕骨架（背这 6 行，代码现场翻译）

```text
softmax : x -= max(keepdim) → e=exp(x) → e/e.sum(keepdim)
CE      : loss = logsumexp(logits) − logit[target]；批量取 mean
LN      : γ·(x−μ)/√(σ²+ε)+β，μσ 沿最后一维，除 D
kmeans  : d=|x−c|²→argmin 分配→簇内均值→|Δc|<tol 停；空簇保留旧中心；多次初始化取 inertia 最小
MHA     : Q,K,V=XW → S=QKᵀ/√dk → mask(−1e9) → rowSoftmax → O=AV → concat 各头 ·Wo
CART    : Gini=1−Σp²；枚举(特征,相邻中点)取加权 Gini 下降最大 → 左右递归；叶取多数类
```

**numpy 六个必会**：`keepdims=True`（聚合后还要逐元素运算时必须加）、`axis=-1`、"axis=k 则该维消失"、`X[:,None,:]` 插轴做广播、`logits[np.arange(N),t]` 交叉索引、`argsort(-s)` 降序下标、`copy()`（赋值是引用）。

**torch 六个坑**：`max(...).values`、参数名 `dim/keepdim`、`masked_fill(True=屏蔽)`、`gather` 代替高级索引、`transpose 后必须 contiguous() 才能 view`、`F.scaled_dot_product_attention` 的 bool mask **语义相反（True=允许）**。

## D. 三句最高分话术

1. **融合 ↔ cross-attention**："我的融合是静态门控，改造会换成 query-based cross-attention：**BEV query 作 Q、图像特征作 K/V**，让权重按位置和内容动态生成——这正是 BEVFormer 与 Q-Former 的共同思路。"
2. **BEV query vs Q-Former**："形式上同类，差别在**几何先验**：BEV query 对应固定世界坐标格子、靠内外参投影，位置物理正确；Q-Former 的 query 无几何约束。前者适合度量精度，后者适合语义检索。"
3. **端侧三问**："我会先问目标 SoC 的**算子白名单、内存预算、是否允许动态分辨率**——我在 MDC610 上做过 ONNX→ATC/AOE→`.om` 全链路，对不支持算子做过解耦+等价改写。"

## E. 不会的题（三步法）

① **缩范围**："您问的是训练侧还是推理侧？" ② **给相邻知识**："这块我没在生产做过，但相邻问题是这样解决的……" ③ **给验证路径**："让我做的话会先用 XX 指标做小规模对照，再放大。"
**面试官容忍"不会"，不容忍"编"。**
