### 3.1 Softmax（+ 数值稳定 + 交叉熵）

```python
import numpy as np

def softmax(x, axis=-1):
    x = x - x.max(axis=axis, keepdims=True)      # 防 exp 溢出，数学上恒等
    e = np.exp(x)
    return e / e.sum(axis=axis, keepdims=True)

def log_softmax(x, axis=-1):
    x = x - x.max(axis=axis, keepdims=True)
    return x - np.log(np.exp(x).sum(axis=axis, keepdims=True))
```

PyTorch 版交叉熵（**高频手撕**）：

```python
import torch
def cross_entropy(logits, target, weight=None):      # logits:[N,C] target:[N] int
    m = logits.max(dim=1, keepdim=True).values
    lse = m.squeeze(1) + torch.log(torch.exp(logits - m).sum(dim=1))
    nll = lse - logits.gather(1, target[:, None]).squeeze(1)
    if weight is not None:
        w = weight[target]
        return (nll * w).sum() / w.sum()
    return nll.mean()
```

追问必答：
- 为什么要减 max？exp 上溢成 inf，再除 inf 得 nan；减常数不改变结果。
- log_softmax 比 softmax 稳在哪？交叉熵直接在对数域算，避免 "先算小概率→取 log" 的下溢；用 logsumexp 恒等式。
- softmax 温度 T 的作用：T↑ 分布更平（蒸馏/采样多样性），T↓ 更尖（argmax 近似）。
- 带 mask 的 softmax：被屏蔽位置置 **-1e9 或 -inf**，注意**整行全屏蔽会出 nan**，工业实现会 `scores.masked_fill(mask, -1e4)` 或对全屏蔽行补 0。
- Softmax vs Sigmoid：多分类互斥 vs 多标签独立（BCEWithLogits 更稳，因为它自带 logsumexp 形式）。
- Label Smoothing 怎么改？target 从 one-hot 变 (1-ε) 的 one-hot + ε/C 均匀。

### 3.2 K-Means

```python
import numpy as np

def kmeans(X, k, iters=100, tol=1e-4, seed=0, n_init=1):
    X = np.asarray(X, dtype=np.float64)
    rng = np.random.default_rng(seed)
    best_labels, best_centers, best_inertia = None, None, np.inf
    for _ in range(n_init):
        idx = rng.choice(len(X), k, replace=False)        # 简单随机初始化
        centers = X[idx].copy()
        labels = np.zeros(len(X), dtype=int)
        for _ in range(iters):
            d = ((X[:, None, :] - centers[None, :, :]) ** 2).sum(-1)   # n*k
            new_labels = d.argmin(1)
            new_centers = centers.copy()
            for j in range(k):
                m = new_labels == j
                if m.any():                               # 空簇：保留旧中心
                    new_centers[j] = X[m].mean(0)
            shift = np.linalg.norm(new_centers - centers)
            centers, labels = new_centers, new_labels
            if shift < tol:
                break
        inertia = ((X - centers[labels]) ** 2).sum()
        if inertia < best_inertia:
            best_labels, best_centers, best_inertia = labels, centers, inertia
    return best_labels, best_centers
```

追问必答：
- 复杂度 O(n·k·d·iters)，k-means++ 初始化把随机初始化的最坏情况压掉。
- k 怎么定：肘部法（inertia 拐点）、轮廓系数 silhouette、Gap statistic、业务约束。
- 假设：簇是**凸的、各向同性、方差相近**；对异常值敏感（可用 k-medoids / trimmed）。
- 与 EM/GMM：k-means 是 GMM 的硬分配特例（等协方差），EM 的 E 步=软分配。
- 空簇处理：保留旧中心 / 取离其他中心最远点。
- 加速：MiniBatch、kd-tree/球树（低维）、三角不等式剪枝（Elkan）。
- 面试官可能顺手问 DBSCAN：密度可达、不需 k、能找任意形状、对 eps/minPts 敏感、高维失效。

### 3.3 Self-Attention / Multi-Head Attention（最可能被要求写的一个）

**先写 Self-Attention（单头）**，再扩多头，最后加 mask。用 PyTorch：

```python
import math, torch, torch.nn as nn, torch.nn.functional as F

def self_attention(x, Wq, Wk, Wv, mask=None):
    # x: [B, L, D]; Wq/Wk/Wv: [D, D]
    Q, K, V = x @ Wq, x @ Wk, x @ Wv                  # [B, L, D]
    scores = Q @ K.transpose(-2, -1) / math.sqrt(Q.size(-1))   # [B, L, L]
    if mask is not None:
        scores = scores.masked_fill(mask, float('-inf'))       # mask=True 表示屏蔽
    attn = torch.softmax(scores, dim=-1)
    return attn @ V, attn
```

**多头（完整、含 mask、可跑）**：

```python
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_head, dropout=0.0):
        super().__init__()
        assert d_model % n_head == 0
        self.h = n_head
        self.d_k = d_model // n_head
        self.w_q = nn.Linear(d_model, d_model)
        self.w_k = nn.Linear(d_model, d_model)
        self.w_v = nn.Linear(d_model, d_model)
        self.w_o = nn.Linear(d_model, d_model)
        self.drop = nn.Dropout(dropout)

    def forward(self, q, k, v, attn_mask=None, key_padding_mask=None):
        B, Lq, _ = q.shape
        Lk = k.size(1)
        # 1) 线性投影 + 拆头: [B,L,D] -> [B,h,L,dk]
        Q = self.w_q(q).view(B, Lq, self.h, self.d_k).transpose(1, 2)
        K = self.w_k(k).view(B, Lk, self.h, self.d_k).transpose(1, 2)
        V = self.w_v(v).view(B, Lk, self.h, self.d_k).transpose(1, 2)
        # 2) 缩放点积
        scores = Q @ K.transpose(-2, -1) / math.sqrt(self.d_k)    # [B,h,Lq,Lk]
        # 3) 两种 mask：因果/结构 mask [Lq,Lk]；padding mask [B,Lk]
        if attn_mask is not None:
            scores = scores.masked_fill(attn_mask.bool(), float('-inf'))
        if key_padding_mask is not None:
            pad = key_padding_mask[:, None, None, :].bool()       # [B,1,1,Lk]
            scores = scores.masked_fill(pad, float('-inf'))
        # 4) softmax 后合并
        attn = self.drop(torch.softmax(scores, dim=-1))
        out = attn @ V                                            # [B,h,Lq,dk]
        out = out.transpose(1, 2).contiguous().view(B, Lq, self.h * self.d_k)
        return self.w_o(out), attn
```

**Numpy 版（若面试官说"别用框架"）**：

```python
def mha_numpy(x, Wq, Wk, Wv, Wo, h, mask=None):
    B, L, D = x.shape
    dk = D // h
    def split(t):                                   # [B,L,D] -> [B,h,L,dk]
        return t.reshape(B, L, h, dk).transpose(0, 2, 1, 3)
    Q, K, V = split(x @ Wq), split(x @ Wk), split(x @ Wv)
    scores = Q @ K.transpose(0, 1, 3, 2) / np.sqrt(dk)           # [B,h,L,L]
    if mask is not None:
        scores = np.where(mask, -1e9, scores)
    scores = scores - scores.max(-1, keepdims=True)
    e = np.exp(scores)
    attn = e / e.sum(-1, keepdims=True)
    out = (attn @ V).transpose(0, 2, 1, 3).reshape(B, L, D)
    return out @ Wo, attn
```

追问必答（**这部分比代码更值分**）：
- **为什么除 √d_k**：q·k 的方差随 d_k 线性增长，不缩放会让 softmax 落到饱和区、梯度消失；缩放使方差归一。
- **复杂度**：时间/显存 O(L²·d)。这就是长上下文贵的根因 → 引出去向：FlashAttention（分块 + 在线 softmax，**省显存不省 FLOPs**）、MQA/GQA（共享 K/V 头，省 KV cache）、稀疏/滑窗注意力、线性注意力、Mamba/SSM。
- **O(L²) 显存怎么省**：FlashAttention 的 tiling + 重计算（不落 L×L 矩阵）、KV cache 量化、GQA。
- **view 后为什么必须 contiguous**：transpose 后内存不连续，view 要求连续，否则报错——实际实现写 `reshape` 或加 `.contiguous()`。
- **mask 语义一定要说清**：True=屏蔽（-inf）、False=保留；padding mask 是 batch 维、causal mask 是 Lq×Lk 下三角。
- **为什么要多头**：不同头学不同子空间/不同依赖模式（位置、句法、指代），可类比 CNN 多通道。
- **LayerNorm 放哪**：Post-LN（原始 Transformer，需 warmup）vs Pre-LN（现代主流，更稳，可去 warmup）；RMSNorm 少了均值中心化，更快。
- **Q/K/V 不同源**：self-attention（同源）vs cross-attention（Q 来自 decoder/query，K/V 来自 encoder，就是 Flamingo/BLIP-2/多模态融合里的融合入口——**这里一定要接上你的经验**）。
- 位置编码：绝对正弦、可学习、RoPE（相对位置、可外推、LLaMA 系）、ALiBi。**RoPE 为什么能外推/怎么扩 context（NTK 插值/位置内插）** 是当前高频追问。

### 3.4 分类树（CART，ID3/C4.5 关系要会讲）

```python
import numpy as np

class Node:
    __slots__ = ("feat", "thr", "left", "right", "value")
    def __init__(self): self.feat = self.thr = self.left = self.right = self.value = None

def _gini(y, n_cls):
    if len(y) == 0: return 0.0
    p = np.bincount(y, minlength=n_cls) / len(y)
    return 1.0 - (p ** 2).sum()

def _build(X, y, depth, max_depth, min_samples_leaf, min_gain, n_cls):
    node = Node()
    node.value = np.bincount(y, minlength=n_cls).argmax()
    # 停止条件：深度、纯节点、样本太少
    if depth >= max_depth or len(np.unique(y)) == 1 or len(y) < 2 * min_samples_leaf:
        return node
    best_gain, best = min_gain, None
    parent = _gini(y, n_cls)
    n = len(y)
    for f in range(X.shape[1]):
        vals = np.unique(X[:, f])
        thrs = (vals[:-1] + vals[1:]) / 2.0
        for t in thrs:
            m = X[:, f] <= t
            nl, nr = m.sum(), n - m.sum()
            if nl < min_samples_leaf or nr < min_samples_leaf:
                continue
            g = parent - (nl * _gini(y[m], n_cls) + nr * _gini(y[~m], n_cls)) / n
            if g > best_gain:
                best_gain, best = g, (f, t, m)
    if best is None:
        return node
    f, t, m = best
    node.feat, node.thr = f, t
    node.left  = _build(X[m],  y[m],  depth + 1, max_depth, min_samples_leaf, min_gain, n_cls)
    node.right = _build(X[~m], y[~m], depth + 1, max_depth, min_samples_leaf, min_gain, n_cls)
    return node

def _predict_one(node, x):
    while node.feat is not None:
        node = node.left if x[node.feat] <= node.thr else node.right
    return node.value

class DecisionTreeClassifier:
    def __init__(self, max_depth=5, min_samples_leaf=1, min_gain=1e-7):
        self.max_depth, self.min_samples_leaf, self.min_gain = max_depth, min_samples_leaf, min_gain
    def fit(self, X, y):
        self.n_cls = int(y.max()) + 1
        self.root = _build(np.asarray(X, float), np.asarray(y, int), 0,
                           self.max_depth, self.min_samples_leaf, self.min_gain, self.n_cls)
        return self
    def predict(self, X):
        return np.array([_predict_one(self.root, x) for x in np.asarray(X, float)])
```

追问必答：
- **划分准则**：ID3 信息增益（偏多值特征，倾向多叉）、C4.5 信息增益率（除法惩罚）、CART 基尼指数（**二叉树**，分类用基尼、回归用 MSE，叶子取均值）。
- **为什么 CART 用基尼不用熵**：二次形式没有 log，快；两者结论高度一致。
- **剪枝**：预剪枝（max_depth/min_samples_leaf/min_gain，快但可能欠拟合，贪心视野短）vs 后剪枝（代价复杂度 CART 的 α，从全树自底向上合并，更准但贵）。
- **过拟合原因**：划分太细，叶子只剩 1 个样本 → 方差爆炸。控制树深 / 叶最小样本 / 后剪枝。
- **连续特征处理**：排序后取中点枚举 O(n·log n·d) 的排序 + O(n·d) 扫描；大样本用分位分桶近似（LightGBM 直方图）。
- **特征重要性**：按该特征分裂带来的加权不纯度下降累积（sklearn 的 gini_importance），偏多值特征；更可靠是置换重要性。
- **推导到 GBDT**：残差/梯度拟合、XGBoost 的二阶 Taylor + 正则（γT + λw²/2）+ 并行建直方图、LightGBM 的 leaf-wise + GOSS + EFB。
- 顺带：随机森林 = bagging + 特征子采样，降方差；树模型不需要归一化、对单调变换不变、不能外推。

# IoU
def iou(box_a, box_b):  # [x1,y1,x2,y2]
    ix1, iy1 = max(box_a[0], box_b[0]), max(box_a[1], box_b[1])
    ix2, iy2 = min(box_a[2], box_b[2]), min(box_a[3], box_b[3])
    iw, ih = max(0., ix2 - ix1), max(0., iy2 - iy1)
    inter = iw * ih
    area_a = max(0., box_a[2]-box_a[0]) * max(0., box_a[3]-box_a[1])
    area_b = max(0., box_b[2]-box_b[0]) * max(0., box_b[3]-box_b[1])
    union = area_a + area_b - inter
    return inter / union if union > 0 else 0.

# NMS
def nms(boxes, scores, thr=0.5):
    order = scores.argsort()[::-1]
    keep = []
    while order.size > 0:
        i = order[0]; keep.append(i)
        if order.size == 1: break
        ious = np.array([iou(boxes[i], boxes[j]) for j in order[1:]])
        order = order[1:][ious <= thr]
    return keep

    return gamma * (x - mu) / np.sqrt(var + eps) + beta

### 4.4 五个模板（现场默写用）

```python
# 1) 快排（含随机化，避免有序数组退化）
import random
def quick_sort(a, l=0, r=None):
    if r is None: r = len(a) - 1
    if l >= r: return a
    p = random.randint(l, r)
    a[l], a[p] = a[p], a[l]
    pivot, i = a[l], l
    for j in range(l + 1, r + 1):
        if a[j] < pivot:
            i += 1
            a[i], a[j] = a[j], a[i]
    a[l], a[i] = a[i], a[l]
    quick_sort(a, l, i - 1); quick_sort(a, i + 1, r)
    return a

# 2) 二分（左边界，防死循环）
def lower_bound(a, x):
    lo, hi = 0, len(a)
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] < x: lo = mid + 1
        else: hi = mid
    return lo

# 3) 滑动窗口（无重复最长子串）
def length_of_longest(s):
    last, left, ans = {}, 0, 0
    for i, c in enumerate(s):
        if c in last and last[c] >= left:
            left = last[c] + 1
        last[c] = i
        ans = max(ans, i - left + 1)
    return ans

# 4) 小顶堆 TopK（n log k）
import heapq
def topk(nums, k):
    h = []
    for x in nums:
        heapq.heappush(h, x)
        if len(h) > k: heapq.heappop(h)
    return h

# 5) 并查集
class DSU:
    def __init__(self, n): self.p = list(range(n)); self.r = [0]*n
    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb: return False
        if self.r[ra] < self.r[rb]: ra, rb = rb, ra
        self.p[rb] = ra
        if self.r[ra] == self.r[rb]: self.r[ra] += 1
        return True
```

## 5. 多模态八股速记（12 问，各 30 秒版）

> 这里是**口头速记版**；完整答案库（96 问，按面试顺序 + 追问 + 项目接口话术 + 融合调控专章）见同目录
> 《华为-多模态大模型-八股知识问答_20261029.docx/md/pdf》。

1. **CLIP 怎么训的**：图像/文本双塔，batch 内 N×N 相似度矩阵，对角为正样本，对称 InfoNCE（in-batch negatives）。温度 τ 可学习。零样本靠 prompt + 文本分类器权重。
2. **CLIP 的局限**：只做粗粒度全局对齐，不擅长计数/空间关系/细粒度；对比学习不考虑词序（bag-of-words 问题）。
3. **BLIP-2 的 Q-Former**：冻结图像塔 + 冻结 LLM，中间用固定数量 learnable query 通过 cross-attention 抽取视觉信息，把可变长 patch 压成固定 token（省 LLM 上下文）。两阶段：表征学习（ITC/ITM/ITG）→ 生成学习（接 LLM 做 LM loss）。
4. **LLaVA 的 projector**：两层 MLP 直接映射视觉 token，简单有效（消融显示比 Q-Former 不差）；两阶段训练=先冻结 LLM 只训 projector（对齐），再解冻部分/全量做指令微调。
5. **ViT vs CNN**：patch 化 + 全局注意力、无归纳偏置、需要大数据或强增广/蒸馏；计算 O(N²)，高分辨率要用窗口/分层（Swin）。
6. **视觉 token 太多怎么办**：Q-Former/Perceiver 压缩、池化、token merge、动态分辨率、只取关键帧。**接你的经验：BEV query 重排与深度加权投影就是"几何感知的 token 组织"**。
7. **位置编码**：正弦/可学习/RoPE/ALiBi；RoPE 保相对位置、LLaMA 系标准；长上下文靠位置内插/NTK/缩放。
8. **训练三阶段**：预训练（对齐）→ SFT（指令遵循）→ 偏好对齐（RLHF/DPO）。DPO 不用 reward model，直接用偏好对做分类式损失。
9. **LoRA**：低秩分解 ΔW=BA，只训 A/B，rank 8~64、alpha 缩放、可合并推理零开销。
10. **幻觉**：视觉 token 与语言先验冲突时模型倾向语言先验（POPE 评测）；缓解=更强视觉监督、负样本、解码策略、RAG。
11. **评测**：MMBench/MMMU/SEED（综合），POPE（幻觉），RefCOCO/Visual Grounding，VideoMME（长视频）。说清"评什么、怎么算分"就够。
12. **端侧/昇腾**：CANN、ATC（ONNX→om）、AOE 调优、量化 INT8/INT4、算子不支持要替换。**你有 ATC/MDC610 真机经验，这题是送分题，务必主动引到这儿**。
